# Тестовая задача.
 
Реализовать систему обработки PDF-документов, состоящую из двух сервисов :
- API Gateway
- Background Worker
 
## Функциональные требования :
 
Для API Gateway необходимо реализовать REST API :
- Загрузка PDF
- Получение списка PDF
- Получение текстового содержимого PDF
 
Для Background Worker :
- Получать сообщения из RabbitMQ
- Извлекать текстовое содержимое из PDF-файла
- Сохранять результат в PostgreSQL
- Обновлять статус обработки документа
 
Не требуется реализовывать :
- Frontend
- Авторизация
- Cложная инфраструктура
 
Основной фокус :
- Backend
- Архитектура
- Работа с очередями
- Работа с БД
 
Взаимодействие сервисов требуется реализовать через RabbitMQ.
Свобода в выборе библиотеки для парсинга PDF.
 
Технологии:
- C#
- ASP.NET Core
- PostgreSQL
- RabbitMQ
- Docker
